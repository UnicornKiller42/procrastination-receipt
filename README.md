# Procrastination receipt

A till receipt for the things you did not do today.

Type one avoided task per line, or add them one at a time. Press **Print receipt**. A narrow paper slip slides out with a price for each task (minutes or guilt units), a subtotal, regret tax, a total, and a barcode. **Print** sends only that slip to the printer.

What you type stays on the page until you reload it. Nothing is saved.

## Open

Open `index.html` in a browser. Double-click the file, or pass it to the browser another way.

To publish with GitHub Pages, deploy the site from the repository root. The page is `index.html`.

## Tests

From this folder:

```bash
node receipt.test.js
```

No install is required.
